# 사용한 데이터 관련

* 사용한 데이터 크기들이 커서 읽을 수 있는 형태로는(csv, xlsx 등) github에 업로드가 불가능합니다.
* asos 데이터는 노트북 내부에서 api를 통해 자체적으로 받을 수 있고, 에어코리아 데이터는 따로 다운로드 받아 colab에 업로드해서 사용할 수 있습니다.
* 에어코리아 데이터 링크: https://airkorea.or.kr/web/last\_amb\_hour\_data?pMENU\_NO=123
* asos 데이터를 다운로드 받을 땐 colab에 기상청 api 센터에서 발급받은 api key를 사용해야 합니다.
