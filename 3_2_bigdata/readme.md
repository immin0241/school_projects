# 빅데이터 프로젝트 보고서: 기상 요인과 미세먼지 농도의 상관관계 분석

## 1. 데이터 선정 이유

미세먼지(PM10, PM25)는 국민 건강과 직결되는 중요한 환경 문제입니다. 대기 오염 농도는 단순히 배출원의 영향뿐만 아니라, 풍향, 강수량, 기온 등 기상 조건에 따라 크게 달라질 수 있습니다. 본 프로젝트는 기상청의 종관기상관측(ASOS) 데이터와 에어코리아의 대기오염 데이터를 결합하여, 기상 요인이 미세먼지 농도에 미치는 영향을 데이터에 기반하여 분석하고 시각화하기 위해 해당 데이터를 선정하였습니다.

## 2. 사용한 데이터와 범위

본 프로젝트에서는 2021년부터 2023년까지 총 3년 치의 데이터를 수집 및 분석하였습니다.

- 기간: 2021년 1월 1일 ~ 2023년 12월 31일

- 지역: 대한민국 전역 (주요 도시 및 관측소 기준)

- 데이터 출처:

	1. 기상 데이터: 기상청 API (기상자료개방포털) - 종관기상관측(ASOS)

	2. 대기오염 데이터: 에어코리아 (AirKorea) - 최종확정 측정자료 (도시대기 측정망 기준)

3. 사용한 데이터프레임의 컬럼명 목록

전처리 및 병합이 완료된 최종 데이터프레임(df)의 주요 컬럼은 다음과 같습니다.

- 시간/날짜: 측정일시, 연, 월, 일, 시, 계절

- 위치 정보: 지역 (예: 서울 중구), 측정소명 (ASOS 관측소), 매핑_측정소명, 측정소ID

- 대기 오염 정보: PM10 (미세먼지), PM25 (초미세먼지)

- 기상 정보:

	- 풍향 (16방위 등), 풍속 (m/s)

	- 온도 (℃), 상대습도 (%)

	- 강수량 (mm)
